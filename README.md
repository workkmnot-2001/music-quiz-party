# 🎵 Music Quiz Party! (ปาร์ตี้เกมทายเพลงสดแบบเรียลไทม์)

เกมปาร์ตี้ตอบคำถามทายเพลงแบบเรียลไทม์ (Multiplayer Real-time Room) เล่นพร้อมกันได้ไม่จำกัดจำนวนคนในห้องเดียว ดึงคลังเพลงและไฟล์เสียงพรีวิวคุณภาพสูง 30 วินาทีจาก **Apple iTunes Search API** แบบสดๆ เพลงจะเล่นพร้อมกันทั้งห้องแบบ Synchronized ทันทีที่เริ่มข้อ!

---

## ✨ ฟีเจอร์ใหม่ที่อัปเดต (v2.0 Updates)

1. **✍️ โหมดพิมพ์ตอบ + ระบบคำใบ้ & ค้นหาเพลงอัตโนมัติ (Typing Mode with Hints & Autocomplete):**
   - ผู้เล่นสามารถพิมพ์ชื่อเพลง หรือชื่อศิลปิน เพื่อตอบคำถาม
   - **ระบบคำใบ้ 3 ระดับ (Progressive Hints):**
     - 💡 **คำใบ้ที่ 1:** บอกจำนวนตัวอักษรของชื่อเพลง และหมวดหมู่เพลง
     - 💡 **คำใบ้ที่ 2:** บอกตัวอักษรขึ้นต้นของชื่อเพลง (เช่น `ขึ้นต้นด้วย "ท..."`)
     - 💡 **คำใบ้ที่ 3:** บอกชื่อศิลปินเจ้าของเพลง (เช่น `ศิลปินคือ "Paper Planes"`)
     - ปลดล็อคตามเวลาอัตโนมัติ หรือกดปุ่ม **"🔓 ขอคำใบ้เพิ่ม"** ได้ทันที
   - **ระบบค้นหาคำตอบอัตโนมัติ (Live Search Dropdown):** ขณะพิมพ์ชื่อเพลงหรือศิลปิน จะมีดรอปดาวน์แนะนำรายชื่อเพลงในคลังขึ้นมาให้กดเลือกได้ทันที สะดวกและแม่นยำ ไม่ต้องกังวลเรื่องพิมพ์ตกหล่น

2. **⏩ ระบบข้ามหลังจากตอบเสร็จ & ข้ามข้อ (Skip / Fast-Forward System):**
   - **ปุ่มข้ามข้อ (Skip / ยอมแพ้):** หากผู้เล่นไม่รู้จักเพลง สามารถกดปุ่ม **"⏩ ข้ามข้อนี้"** เพื่อผ่านได้ทันที โดยระบบจะนับว่าตอบแล้ว เพื่อไม่ต้องเสียเวลารอ
   - **ระบบข้ามเวลารอ (Host Fast-Forward):** หัวหน้าห้องสามารถกดปุ่ม **"⚡ ข้ามเวลารอ (เฉลยทันที)"** เพื่อตัดเข้าหน้าเฉลยได้ทันทีเมื่อทุกคนพร้อม
   - เมื่อทุกคนในห้องตอบหรือข้ามครบ ระบบจะตัดเข้าหน้าเฉลยทันทีโดยอัตโนมัติ
   - ในหน้าเฉลย หัวหน้าห้องสามารถกด **"ข้อถัดไป ➡️"** ได้ทันทีโดยไม่ต้องรอตัวจับเวลา

3. **🔽 ระบบเลือกแบบดรอปดาวน์สไตล์มินิมอล (Minimalist Dropdown UI):**
   - เปลี่ยนจากการ์ดขนาดใหญ่มาเป็นดรอปดาวน์กระจกใส (Glassmorphism Dropdowns) เรียบหรู สะอาดตา
   - ปรับแต่ง **โหมดเกม (ช้อยส์ / พิมพ์ตอบ / ผสม)**, **หมวดหมู่หลัก**, **หมวดหมู่ย่อย**, **จำนวนข้อ** และ **เวลาต่อข้อ** ได้อย่างรวดเร็ว

4. **📱 ระบบแถบข้างซ้ายแสดงห้อง & ล็อบบี้ (Left Sidebar Layout):**
   - บนหน้าจอคอมพิวเตอร์และแท็บเล็ต: แสดงแถบข้อมูลห้อง รหัสห้อง ปุ่มแชร์ลิงก์ QR Code และรายชื่อผู้เล่นพร้อมคะแนนและสถานะการตอบแบบสดๆ ทางด้านซ้ายตลอดเวลา
   - บนหน้าจอมือถือ: มีปุ่ม **"👥 ห้อง (X)"** ด้านบนสำหรับสไลด์เปิดแถบข้าง (Drawer) ออกมาดูได้อย่างคล่องตัว

## 🚀 วิธีเปิดใช้งานและเข้าเล่น

### เริ่มต้นเซิร์ฟเวอร์
```bash
npm start
# หรือ
node server/index.js
```

### การเข้าเล่น
- **เล่นบนเครื่องตัวเอง:** เข้าผ่านเว็บเบราว์เซอร์ที่ **`http://localhost:3000`**
- **เล่นกับเพื่อนในวง Wi-Fi เดียวกัน:** ให้เพื่อนเข้าผ่านลิงก์ IP วงแลน (เช่น **`http://192.168.1.33:3000`**) หรือเปิด QR Code บนหน้าจอให้เพื่อนสแกนเข้าห้องได้ทันที
